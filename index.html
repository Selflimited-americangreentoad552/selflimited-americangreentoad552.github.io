🛠 How to use the search feature

Once you install the tool, you can search your files immediately. Open the application from your desktop or start menu.

  • Select Folder: Click the browse button to choose the folder containing your documents.
  • Enter Text: Type the keyword or phrase you want to find into the search box.
  • Start Search: Press the search button. The tool begins indexing and scanning all supported files in the selected folder.
  • View Results: The tool lists every file that contains your text. You can click on any result to see the specific line where the text matches.
